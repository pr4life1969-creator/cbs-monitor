CBS Monitor — Simple step-by-step guide (Plain English)

This guide helps you run the CBS Monitor app on your Samsung phone without programming.

What you have in this ZIP

  • single-file.html — easiest: open in Chrome on your phone and run the app.
  • bundle/ — full web app folder (for hosting or Android project).
  • android_project/ — optional Android Studio project (if you want an APK).
  • offline_bundle/README.txt — how to make the app fully offline by downloading model files once.

Step-by-step: Run now (no programming)

  1. Download and extract the ZIP on your phone (or transfer via USB).
  2. Open the Files app and tap single-file.html and choose Chrome to open.
  3. When Chrome asks, allow Camera and Microphone.
  4. Inside the app, tap Prefetch Models (one-time). This needs internet only once.
  5. Go to Enroll → enter a name (e.g., P01) → tap Enroll Face and look at the camera for 5 quick samples.
  6. Start Mic → record a 30–60s neutral baseline (label it “baseline”).
  7. Enroll Speaker MFCC: speak a bit with the mic on, then tap Enroll Speaker to collect voice features for that person.
  8. Dashboard → Start Mic → Start Trial → ask your question → End Trial. Use Data tab to export recordings or view confusion matrix.
  9. To install on Home screen: Chrome menu → Add to Home screen. Now it behaves like an app.

Troubleshooting

  • If camera or mic don't work, check Chrome has permissions in Android Settings > Apps > Chrome > Permissions.
  • If face-recognition fails first time, Prefetch Models failed — ensure you're online and try Prefetch again.
