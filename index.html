CBS Monitor — Quick Start

Run on your phone (no programming)

  1. Open this file in Chrome.
  2. Allow Camera & Microphone when prompted.
  3. Tap Prefetch Models (one-time online step).
  4. Enroll face, record baseline, enroll speaker MFCCs.
  5. Dashboard → Start Mic → run trials. Add to Home screen for app-like use.

Need help?

See README_for_non_programmers.html included in this package for step-by-step pictures and instructions in plain English.
